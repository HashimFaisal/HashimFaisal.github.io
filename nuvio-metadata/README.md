# Dabbour metadata addon for Nuvio

Static Stremio-compatible metadata addon for the series `tmdb:134362`.

- Manifest: `https://hashimfaisal.github.io/nuvio-metadata/manifest.json`
- Metadata response: `meta/series/tmdb:134362.json`
- Includes season 1 (34 episodes) and season 2 (35 episodes), using episode IDs compatible with CinemaBox Next: `tmdb:134362:<season>:<episode>`.
- This is a static, series-specific metadata package. It does not resolve or host video streams.
- Add the addon in Nuvio and move it above the existing TMDB metadata addon so its first valid metadata response is selected.

Episode numbering and air dates are based on TheTVDB's aired-order listing for Al-Dabour.
